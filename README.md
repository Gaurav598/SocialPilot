## Key Features

* 🔐 Authentication with **Clerk**
* 🔗 Connect and manage social media accounts
* 📱 Multiple social media channel support
* 📝 Create and manage posts
* 🤖 AI Assistant to generate, shorten, rephrase, and expand posts
* 🧠 Multi-agent AI architecture for research, content, optimization, repurposing, scheduling, and analytics
* 🔎 RAG and semantic search primitives for writing style, brand voice, previous posts, and performance context
* 🗂️ Persistent memory model with short-term, long-term, episodic, and semantic memory
* 📊 AI command center with analytics, social listening, approvals, and pipeline management
* 🛡️ Security headers, rate limits, audit-log schema, and production checklist
* 🚢 Docker, Docker Compose, CI workflow, health checks, and load-test smoke script
* 👀 Custom preview components for each channel
* 📅 Calendar & List View
* ⏰ Automated post scheduling with cron jobs
* 📌 Kanban board for organizing content ideas
* ✨ AI-powered content idea generation
* 🌐 Built with **Next.js, React, Inngest, Clerk & Insforge**
* 🎨 Styled with **Tailwind CSS + Shadcn/UI**
* 🚀 Full-stack and deployment-ready
