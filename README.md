# SocialPilot

SocialPilot is an advanced AI-powered social media operating system designed to automate your content lifecycle, scheduling, and analytics across multiple platforms.

## Features
- **Multi-Agent Orchestration**: Specialized agents for research, content, optimization, repurpose, scheduling, and analytics.
- **Automated Social Publishing**: Background jobs process and publish your content automatically.
- **RAG-Backed Memory System**: Contextual brand voice enforcement.
- **Multi-Tenant Org Architecture**: Granular Workspaces, Organizations, and Role-Based Access Control (RBAC).

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Configure your `.env` file based on `.env.example`.
4. Run `npm run dev` to start the development server.
